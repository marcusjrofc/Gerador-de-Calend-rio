# Gerador de Calendário em Python 📅

Um script simples e interativo em Python para gerar e exibir o calendário mensal de qualquer ano e mês escolhido pelo usuário.

⚙️ **Funcionalidades**

* **Seleção Personalizada:** Permite informar qualquer mês (de 1 a 12) e ano desejado.
* **Validação de Entrada:** Verifica se o número do mês é válido, exibindo um aviso caso esteja fora do intervalo correto.
* **Módulo Nativo:** Utiliza a biblioteca padrão do Python, dispensando a instalação de dependências externas.

🛠️ **Tecnologias Utilizadas**

* **Python 3**
* Módulo nativo `calendar`

🚀 **Como Executar**

1. Certifique-se de que tem o Python instalado no seu computador[cite: 1].
2. Guarde o código do gerador num ficheiro chamado `calendario.py`[cite: 1].
3. Abra o terminal ou a linha de comandos do seu sistema[cite: 1].
4. Navegue até à pasta onde guardou o ficheiro[cite: 1].
5. Execute o seguinte comando[cite: 1]:

```bash
python calendario.py
